# 调酒模拟器设计风格

## 设计哲学

### 色彩方案
- **主色调**：深炭黑 (#1a1a1a) 和深棕褐色 (#2d1810)
- **强调色**：琥珀金 (#d4af37) 和铜色 (#b87333)
- **辅助色**：深墨绿 (#1a3a2e) 和酒红 (#722f37)
- **文本色**：象牙白 (#f8f8ff) 和浅金 (#f5deb3)

### 字体设计
- **标题字体**：Noto Serif SC (粗体) - 优雅的衬线字体，营造高端感
- **正文字体**：Noto Sans SC (常规) - 清晰的无衬线字体，确保可读性
- **装饰字体**：ZCOOL XiaoWei - 用于特殊标题，增加艺术感

### 视觉语言
- **奢华酒吧氛围**：深色背景营造夜晚酒吧的神秘感
- **金色点缀**：象征高端酒具和琥珀色的酒液
- **玻璃质感**：透明和半透明效果模拟玻璃器皿
- **柔和光影**：营造温暖的酒吧照明效果

## 视觉效果

### 使用的库和效果
- **Anime.js**：流畅的材料选择动画和按钮交互
- **p5.js**：创造酒液混合的粒子效果和背景光影
- **ECharts.js**：心情和口味偏好的可视化图表
- **Splide.js**：材料选择的轮播展示
- **Matter.js**：冰块和水果片的物理掉落效果

### 动画效果
- **材料选择**：点击时的金色光晕扩散效果
- **心情切换**：渐变色彩过渡和轻微的浮动动画
- **调酒过程**：液体混合的颜色渐变和气泡效果
- **结果展示**：饮品图片的渐现和文字打字机效果

### Hero区域设计
- **背景**：深色渐变配合p5.js创造的动态光影效果
- **主标题**：大型渐变文字"创造你的专属饮品"
- **副标题**：优雅的描述文字介绍调酒体验
- **装饰元素**：抽象的酒杯轮廓和金色粒子飘散

### 交互反馈
- **悬停效果**：材料卡片的3D倾斜和金色边框发光
- **点击反馈**：按钮的下沉效果和金色波纹扩散
- **选择指示**：选中项目的高亮边框和轻微缩放
- **加载状态**：优雅的旋转调酒器图标

### 页面布局特色
- **卡片设计**：磨砂玻璃效果的卡片承载内容
- **网格系统**：整齐的材料选择和配方展示
- **响应式设计**：适配各种屏幕尺寸的优雅布局
- **视觉层次**：通过大小、颜色和间距建立清晰的信息层级
