# 调酒模拟器项目大纲

## 项目结构

### 核心文件
- `index.html` - 主调酒页面
- `result.html` - 调酒结果展示页面  
- `recipes.html` - 配方库浏览页面
- `main.js` - 主要JavaScript逻辑
- `resources/` - 图片和媒体资源文件夹

### 页面功能分配

## 1. 主页面 (index.html)
**功能**: 调酒创作界面
- **Hero区域**: 调酒台背景图 + 主标题
- **材料选择区**: 
  - 基酒选择 (伏特加、威士忌、朗姆、金酒、龙舌兰)
  - 果汁选择 (柠檬汁、青柠汁、橙汁、西柚汁)
  - 糖浆选择 (简单糖浆、香草糖浆、榛果糖浆)
  - 装饰物选择 (薄荷叶、柠檬片、樱桃、橄榄)
- **心情选择器**: 
  - 开心、失落、兴奋、浪漫、疲惫、庆祝
  - 每个心情配有对应的图标和颜色
- **口味偏好设置**:
  - 甜度滑块 (1-10)
  - 酸度滑块 (1-10) 
  - 酒精浓度滑块 (1-10)
  - 果味强度滑块 (1-10)
- **调酒按钮**: 大型金色按钮，点击触发配方生成
- **预览区域**: 实时显示当前选择组合

## 2. 结果页面 (result.html)
**功能**: 展示生成的专属饮品
- **饮品展示区**: 
  - AI生成的饮品图片
  - 饮品名称 (智能生成)
  - 个性化描述文案
- **配方详情**:
  - 材料清单和用量
  - 详细调酒步骤
  - 装饰建议
- **互动功能**:
  - 保存到配方库
  - 重新调酒按钮
  - 分享功能
- **心情匹配说明**: 解释为什么推荐这个配方

## 3. 配方库页面 (recipes.html)
**功能**: 浏览和管理保存的配方
- **搜索和筛选**:
  - 按心情筛选
  - 按口味筛选  
  - 按材料搜索
- **配方网格展示**:
  - 配方卡片网格
  - 每个卡片显示饮品图、名称、心情标签
- **收藏功能**:
  - 标记喜爱配方
  - 删除不需要的配方
- **统计信息**: 
  - 调酒次数
  - 最喜爱的心情和口味

## 技术实现

### 前端技术栈
- **HTML5** + **CSS3** + **JavaScript ES6**
- **Tailwind CSS** - 样式框架
- **Anime.js** - 动画效果
- **p5.js** - 背景特效和粒子效果
- **ECharts.js** - 数据可视化
- **Splide.js** - 轮播组件

### 核心功能模块
1. **配方生成算法**: 基于心情和偏好智能匹配
2. **数据存储**: localStorage保存用户配方
3. **图片生成**: 集成AI图像生成API
4. **动画系统**: 流畅的交互动画
5. **响应式布局**: 适配各种设备

### 数据结构
```javascript
// 配方数据结构
{
  id: string,
  name: string,
  description: string,
  mood: string,
  ingredients: array,
  steps: array,
  image: string,
  preferences: object,
  createdAt: date
}
```

## 用户体验流程
1. 进入主页面 → 选择材料 → 设置心情和口味 → 点击调酒
2. 系统生成配方 → 跳转到结果页面 → 查看专属饮品
3. 可选择保存配方 → 在配方库中查看历史记录
4. 支持重新调酒和分享功能
